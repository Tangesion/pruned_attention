## 1. 参考示例格式特征

> 当用户上传别人论文章节后，提取的格式特征记录于此。后续书写一律遵循。

**来源**：华中科技大学硕士论文第4章（SpGEMM硬件加速器SpaHet，hhq_paper.md）

- **章节层级**：三级标题，编号用阿拉伯数字+点（如 4 → 4.1 → 4.2.1）
- **段落模式**：章首总括段概述全章内容；每节结构：目的 → 设置/方法 → 结果数据 → 原因分析 → 小结
- **图表风格**：表标题在上方（"表4.1 实验平台主机端环境"），图标题在下方（"图4.1 整体性能对比"）；引用方式："如图X所示"、"如表X所列出"、"实验结果如图X所示"
- **过渡手法**："首先...其次...最后..."递进式；"接下来，将..."引出新节；"综上所述，..."总结；"为了全面评估..."引出实验目的
- **数据呈现**：倍数精确到小数点后2位（"7.71倍""2.74倍"）；环境参数用表格；性能对比用柱状图/折线图；行内引用关键数据
- **分析深度**：深度分析型——先给结果数据 → 再解释"主要归功于/主要源自" → 回扣到设计动机；消融实验采用增量叠加（baseline → +A → +A+B → +A+B+C）
