# 硕士论文书写风格规范

## 学术论文语言规范

### 术语处理
- 首次出现：中文名（English Full Name, Abbreviation）
- 后续使用：直接用缩写或中文名
- 示例：
  - "键值缓存（Key-Value Cache, KV Cache）"
  - "困惑度（Perplexity, PPL）"
  - "大语言模型（Large Language Model, LLM）"

### 常用学术表达

| 场景 | 推荐表达 | 避免表达 |
|------|---------|---------|
| 引出结果 | 实验结果表明/如表X所示 | 可以看到/我们发现 |
| 对比分析 | 相较于X方法，本文方法在Y指标上提升了Z% | 比X好了Z% |
| 解释原因 | 这主要归因于/其根本原因在于 | 因为/所以 |
| 程度描述 | 显著/大幅/略微 | 很大/非常/稍微 |
| 总结 | 综上所述/上述实验验证了 | 总的来说 |
| 人称 | 本文/本章/本节 | 我/我们 |

### 数据引用格式
- PPL数据：保留2位小数，如 "PPL为9.18"
- 百分比：保留1位小数，如 "Recall达到96.3%"
- 对比提升：使用相对提升百分比，如 "相比基线提升了12.5%"

### 段落结构
1. **实验描述段**：目的 → 设置 → 方法
2. **结果展示段**：引用图表 → 罗列关键数据点
3. **分析讨论段**：解释现象 → 归因 → 与第三章理论的呼应

### 过渡语句模板
- 章节间："在验证了X的有效性后，本节进一步分析Y的影响。"
- 实验间："为了深入理解X对整体性能的贡献，本文设计了消融实验。"
- 结论引出："上述实验结果从X、Y、Z三个维度验证了本文方法的有效性。"
