# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

- **Install Dependencies**: `pip install -r requirements.txt`
- **Install Package (Editable)**: `pip install -e .`
- **Calibration**: Analyze base model to find sensitive dimensions.
  `python scripts/run_calibration.py --model_path <llama_path> --output_path indices.json`
- **Distillation**: Fine-tune small projection weights.
  `python scripts/run_distillation.py --model_path <llama_path> --indices_path indices.json --save_path ./distilled_model`
- **Evaluation (Perplexity)**:
  - Standard: `python scripts/run_perplexity_test.py --model_path <llama_path> --indices_path indices.json`
  - PG19/Long Context: `python scripts/run_pg16_ppl_test.py --base-model <path> --eval-original` (See script for compressed/H2O args)
- **LoRA Fine-tuning**: `python scripts/run_lora_finetuning.py`
- **Streaming Inference**: `python scripts/run_streaming_inference.py`

## Architecture

This project implements a compressed Key-Value (KV) cache for Llama models using a proxy-based "scout" attention mechanism.

- **Source (`src/pruned_attention/`)**:
  - `attention.py`: `CompressedLlamaAttention`. Implements the "scout" attention to identify important KV pairs before full attention.
  - `modeling_llama.py`: Modified Hugging Face Llama model wrapper (`LlamaForCausalLM`, `LlamaModel`) to integrate compressed attention.
  - `calibration.py`: Tools for analyzing attention sensitivity (`apply_compression_to_model`) to generate `indices.json`.
  - `distillation.py`: Layer-wise distillation logic to align compressed attention with original behavior.
  - `utils.py`: Helpers, including `PseudoQuantizer`.

- **H2O Attention (`src/h2o_attention/`)**:
  - Contains baseline implementations or comparisons (e.g., `convert_kvcache_llama_heavy_recent`).

- **Scripts (`scripts/`)**:
  - `run_calibration.py`: Step 1 of compression (Sensitivity Analysis).
  - `run_distillation.py`: Step 2 of compression (Training small probes).
  - `run_pg16_ppl_test.py`: Evaluation script for PG19 dataset, supporting parallel PPL and H2O comparison.

- **Data Artifacts**:
  - `indices.json`: Generated by calibration, specifies which KV dimensions to retain.
  - `small_attn_weights.pt`: Generated by distillation, contains the trained scout layer weights.
